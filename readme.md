# 📝 Flask Todo App

A simple **Todo List Web Application** built using **Flask** and **SQLite**.  
This app allows users to add, view, and delete tasks in a minimal and easy-to-use interface.

---

## 🚀 Features
- Add new tasks with title and description
- View all saved tasks
- Delete tasks when completed
- Stores tasks in a **SQLite database**
- Auto timestamp for task creation

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask, SQLAlchemy
- **Database:** SQLite
- **Frontend:** HTML (Jinja2 Templates)
